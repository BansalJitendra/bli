# video-gallery

Custom **video** block. Purpose: Video gallery with a featured player and a playlist of thumbnails..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: featured video + playlist items (thumbnail, caption, link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
