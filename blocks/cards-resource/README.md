# cards-resource

Custom **cards** block. Purpose: Scrolling set of resource cards (thumbnail, title, description, Watch Now)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: thumbnail, title, description, CTA per card.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
