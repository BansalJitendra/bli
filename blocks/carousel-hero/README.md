# carousel-hero

Custom **carousel** block. Purpose: Rotating hero slides (eyebrow, headline, code, feature bullets, celebrity image + badge)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: image + rich content (eyebrow, headline, bullets) per slide.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
