# cards-benefit

Custom **cards** block. Purpose: Grid of numbered benefit items (number, title, paragraph — no image)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: number, title, paragraph per item.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
