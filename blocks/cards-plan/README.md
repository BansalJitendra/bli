# cards-plan

Custom **cards** block. Purpose: Scrolling set of plan cards (eyebrow, name, benefits list, Buy Now / Know More)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: eyebrow, name, benefits list, two CTA buttons per card.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
