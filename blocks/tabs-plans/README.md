# tabs-plans

Custom **tabs** block. Purpose: Tab switcher across plan sets; each panel holds a plan-cards set..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: tab title + panel content per tab.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
