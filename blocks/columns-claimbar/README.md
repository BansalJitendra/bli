# columns-claimbar

Custom **columns** block. Purpose: Full-width band with a claims-settled counter and an "I want to" help selector, side by side..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: two content groups side by side on a band.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
