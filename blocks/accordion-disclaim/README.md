# accordion-disclaim

Custom **accordion** block. Purpose: Single expandable disclosure row revealing long legal fine print..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: label (summary) + long fine print (body).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
