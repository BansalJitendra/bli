# cards-category

Custom **cards** block. Purpose: Row of life-insurance category cards (icon, title, benefit pill)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: icon, title, benefit pill per card.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
