# cards-contact

Custom **cards** block. Purpose: Row of contact info cards (title tab, phones/timings/emails, optional button)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: title tab, contact details, optional button per card.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
