# carousel-review

Custom **carousel** block. Purpose: Rotating testimonial cards (title, quote, review, avatar + name + stars)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: quote, review, avatar, name, star rating per slide.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
