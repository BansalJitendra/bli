# cards-quicklink

Custom **cards** block. Purpose: Row of service shortcut cards (icon + label)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: icon and label per shortcut.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
