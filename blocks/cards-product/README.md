# cards-product

Custom **cards** block. Purpose: Row of promotional product mini-cards (icon, tag pill, title, benefit line)..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: icon, tag pill, title, benefit line per card.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
